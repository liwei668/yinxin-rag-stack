## 💡 核心功能

### 1. 🤖 AI Agent（智能助手）

**不只是聊天，是真正能干活的AI员工**

- ✅ **浏览器自动化** - AI 真实操作浏览器、打开网页、填写表单、点击按钮
- ✅ **任务规划** - 自动拆解复杂任务，逐步执行
- ✅ **多轮对话** - 记忆上下文，理解复杂意图
- ✅ **工具调用** - 自动调用搜索、计算、文件处理等工具

**应用场景**：
- 🔥 自动填写表单、申报税务
- 🔥 自动抓取竞品价格、整理表格
- 🔥 自动完成重复性办公任务

### 2. 💰 智能财税记账

**全行业独有，小微企业专属**

- ✅ **自动记账** - AI 自动识别票据、生成凭证
- ✅ **自动报表** - 一键生成资产负债表、利润表
- ✅ **自动结账** - 月末自动结账、自动转账
- ✅ **财税合规** - 内置会计准则，自动合规检查

**应用场景**：
- 小微企业日常记账
- 发票自动识别归档
- 税务申报辅助

### 3. 📚 RAG 知识库（智能问答）

**让AI精准理解你的业务知识**

- ✅ **多格式支持** - PDF/Word/Excel/TXT/Markdown
- ✅ **智能解析** - 自动提取文本、保留表格结构
- ✅ **向量检索** - 语义相似度匹配，精准问答
- ✅ **知识管理** - 分类整理、易于维护

**应用场景**：
- 企业内部知识库问答
- 产品文档智能客服
- 规章制度查询

### 4. 🎙️ 语音合成（TTS）

**让AI开口说话**

- ✅ **多引擎支持** - 阿里云/腾讯云/百度/微软
- ✅ **自然语音** - 支持语速、音调调节
- ✅ **流式输出** - 实时生成，无需等待
- ✅ **多语言** - 中文、英文等多语种

### 5. 📊 管理后台

**一站式配置，简洁易用**

- ✅ **用户管理** - 权限控制、安全审计
- ✅ **提词器管理** - 模板编辑、变量配置
- ✅ **系统配置** - API配置、语音配置
- ✅ **日志分析** - 调用统计、问题排查

## 📦 部署方案

### 方案一：Docker 一键部署（推荐）

```bash
# 1. 克隆项目
git clone https://github.com/liwei668/yinxin-rag-stack.git
cd yinxin-rag-stack

# 2. 一键启动
docker-compose up -d

# 3. 访问 http://your-ip:3000
```

### 方案二：手动部署

```bash
# 1. 安装 Node.js 18+
node -v  # 需要 >= 18.0.0

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local

# 4. 开发模式
npm run dev

# 5. 生产模式
npm run build
npm run start
```

### 方案三：Netlify 部署

一键部署到 Netlify：[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/liwei668/yinxin-rag-stack)
