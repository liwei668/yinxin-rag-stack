# Yinxin.AGI.ai - RAG 系统架构设计文档

## 📋 概述

本文档描述了 **Yinxin.AGI.ai** 知识库 RAG（Retrieval-Augmented Generation）系统的整体架构设计，包括数据模型、服务层、API接口、权限体系和扩展规划。

RAG 系统是 Yinxin.AGI.ai 平台的核心组件之一，为企业知识管理和智能问答提供强大支持。

## 📊 数据模型设计

| 字段 | 类型 | 说明 |

## 🔐 权限体系设计

### 权限级别

| 级别 | 说明 | 权限范围 |
|------|------|----------|
| READ | 只读 | 查看文档、搜索、检索 |
| WRITE | 写入 | 上传、编辑、移动文档 |
| ADMIN | 管理 | 删除、权限管理、成员管理 |

### 可见性规则

| 可见性 | 访问规则 |
|--------|----------|
| private | 仅所有者可访问 |
| team | 团队成员可访问 |
| public | 所有人可访问 |

### 权限检查流程

```
1. 检查是否是所有者 → 是 → 全部权限
2. 检查可见性 → public → READ权限
3. 检查团队成员身份 → 是 → 根据角色分配权限
4. 其他 → 无权限
```

## 🔄 三元组去重规则

### 去重策略

文件上传时进行**三元组去重检查**：

1. **fileName** - 文件名
2. **fileSize** - 文件大小（字节）
3. **fileHash** - MD5哈希值

### 去重流程

```
1. 计算文件MD5哈希
2. 查询数据库：fileName + fileSize + fileHash
3. 找到匹配 → 返回已有文档，不重复存储
4. 未找到 → 保存新文档
```

### 存储路径规则

```
data/knowledge/raw/{hash前两位}/{hash}.{扩展名}
```

示例：
```
data/knowledge/raw/a1/a1b2c3d4e5f6...pdf
```

## 🔌 API接口规范

### 知识库接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/knowledge | 获取知识库列表 |
| POST | /api/knowledge | 创建知识库 |
| GET | /api/knowledge/:id | 获取知识库详情 |
| PUT | /api/knowledge/:id | 更新知识库 |
| DELETE | /api/knowledge/:id | 删除知识库 |

### 文档接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/knowledge/documents | 获取文档列表 |
| POST | /api/knowledge/documents | 上传文档 |
| GET | /api/knowledge/documents/:id | 获取文档详情 |
| PUT | /api/knowledge/documents/:id | 更新文档 |
| DELETE | /api/knowledge/documents/:id | 删除文档 |

## 🛡️ 安全考虑

1. **权限隔离**：所有检索操作都经过权限检查
2. **数据加密**：敏感数据加密存储
3. **审计日志**：所有操作记录审计日志
4. **软删除**：删除操作先进入回收站
5. **API兼容**：旧API保持向后兼容
