## 流程说明

1. **用户发送消息**：用户在聊天界面输入问题
2. **路由接收请求**：`app/api/chat/route.ts` 接收POST请求
3. **检测搜索需求**：检查消息是否包含搜索关键词
4. **调用搜索API**：如果需要搜索，调用百度搜索API
5. **处理搜索结果**：获取并格式化搜索结果
6. **整合消息**：将搜索结果添加到原始消息中
7. **调用DeepSeek API**：将增强消息发送给AI模型
8. **生成回答**：AI基于原始问题和搜索结果生成回答
9. **返回响应**：将回答返回给用户

## 技术实现

- **搜索触发**：基于关键词匹配，在 `app/api/chat/route.ts` 中实现
- **API调用**：通过 `src/api/apiManager.ts` 统一管理
- **搜索结果处理**：在 `app/api/chat/route.ts` 中格式化
- **AI响应生成**：通过 DeepSeek API 生成综合回答
