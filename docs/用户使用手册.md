## 1. 产品简介

**Yinxin.AGI.ai（引信）** 是一款全栈式私有化 AI 智能体平台，集成了智能问答、文档识别、数据分析、知识库管理、浏览器自动化等多种能力，旨在为用户提供一站式 AI 助手体验。

### 核心功能

| 功能模块 | 说明 |
|---------|------|
| 智能对话 | 多模型支持、联网搜索、知识库增强、数学公式渲染 |
| Agent 引擎 | 真实浏览器自动化、多轮推理、任务队列 |
| 知识库 RAG | 文档上传解析、向量化检索、树形结构管理 |
| 智能记账 | 凭证管理、科目管理、财务报表、AI 对话记账 |
| 记忆系统 | 偏好提取、话题连续性、重复意图检测 |
| 多媒体 | 图片识别、语音识别、语音合成、文生视频 |
| 数据分析 | 股票实时行情、热门股票、趋势分析 |
| 文档编辑 | 富文本编辑器、AI 润色、导出 Word/PDF |

## 2. 快速入门

### 2.1 注册与登录

1. 打开系统首页，点击右上角 **登录/注册** 按钮
2. 填写用户名、邮箱和密码完成注册
3. 使用注册的邮箱和密码登录系统

### 2.2 首页功能入口

登录后进入首页，可以看到以下功能卡片：

| 卡片 | 功能 | 说明 |
|------|------|------|
| 文生视频 | AI 视频生成 | 输入文字描述，生成视频 |
| 智能客服 | 智能对话 | 与 AI 进行多轮对话 |
| 财税法合 | 知识库问答 | 基于企业知识库的专业问答 |
| 智能记账 | AI 记账 | 通过对话自动生成记账凭证 |
| 数据分析 | 股票分析 | 实时股票行情与数据分析 |
| Agent引擎 | 自动化操作 | AI 自动操控浏览器完成任务 |

### 2.3 开始对话

点击 **智能客服** 卡片或直接在底部输入框输入问题，即可开始与 AI 对话。

## 3. 智能对话

### 3.1 基本对话

在底部输入框输入问题，按 **Enter** 或点击发送按钮即可。

### 3.2 模型选择

点击输入框上方的模型下拉菜单，可以选择不同的 AI 模型：

- **DeepSeek** — 通用对话模型
- **Qwen** — 阿里云通义千问
- **Ollama 本地模型** — 本地部署的开源模型

### 3.3 联网搜索

点击输入框右侧的 **联网搜索** 按钮，AI 将自动搜索互联网获取最新信息来回答问题。

### 3.4 知识库增强

当问题涉及企业业务（税务、财务、法规等）时，AI 会自动检索知识库中的相关资料，优先基于企业知识回答。

### 3.5 对话管理

在左侧边栏中，您可以：

| 操作 | 说明 |
|------|------|
| 新建对话 | 点击左上角 **+** 按钮 |
| 搜索对话 | 在搜索框中输入关键词 |
| 置顶对话 | 鼠标悬停在对话上，点击 **📌** 图标 |
| 重命名对话 | 鼠标悬停在对话上，点击 **✏️** 图标 |
| 删除对话 | 鼠标悬停在对话上，点击 **🗑️** 图标 |

### 3.6 消息操作

鼠标悬停在 AI 回复消息上，可以看到以下操作按钮：

| 按钮 | 功能 |
|------|------|
| 📋 复制 | 复制消息内容到剪贴板 |
| 🔊 播放 | 语音朗读消息内容 |
| 🔄 重新生成 | 重新生成 AI 回复 |
| ⋯ 更多 | 导出为 Word/PDF/Markdown |

### 3.7 文件上传

点击输入框左侧的 **📎** 按钮，可以上传以下类型的文件：

- 文本文件（.txt）
- Word 文档（.docx）
- PDF 文件（.pdf）
- Excel 表格（.xlsx）
- 图片文件（.jpg/.png）

上传后 AI 会自动解析文件内容并回答相关问题。

## 4. Agent 自动化引擎

### 4.1 什么是 Agent

Agent 是 AI 的自动化能力，可以让 AI 像人一样操控浏览器，自动完成网页操作任务，例如：

- 在网站上搜索信息
- 填写表单
- 截取网页数据
- 自动化重复性操作

### 4.2 使用方式

**方式一：通过对话触发**

在对话中描述需要 Agent 执行的任务，AI 会判断是否需要启动 Agent。

**方式二：通过 Agent 控制台**

1. 点击首页的 **Agent引擎** 卡片进入 Agent 控制台
2. 在左侧控制面板中输入任务描述
3. 点击 **启动** 按钮
4. 在右侧浏览器工作区观察 AI 的操作过程

### 4.3 任务状态

Agent 任务有以下状态：

| 状态 | 说明 |
|------|------|
| 等待中 | 任务已创建，等待执行 |
| 执行中 | Agent 正在执行任务 |
| 暂停 | 任务被暂停（需要人工确认） |
| 已完成 | 任务执行成功 |
| 已取消 | 任务被取消 |
| 失败 | 任务执行失败 |

### 4.4 人工介入

当 Agent 遇到不确定的操作时，会暂停并请求人工确认。您可以在弹出的确认卡片中选择：

- **允许** — 继续执行
- **拒绝** — 取消该步骤

## 5. 知识库（RAG）

### 5.1 什么是知识库

知识库（RAG）是一种增强 AI 回答准确性的技术。上传企业文档后，AI 在回答相关问题时会优先参考知识库中的资料。

### 5.2 管理知识库

进入 **管理后台 → RAG管理**，可以：

1. **上传文档** — 支持 TXT、PDF、Word、Excel 格式
2. **查看文档列表** — 查看已上传的文档及处理状态
3. **删除文档** — 移除不需要的文档
4. **管理知识库结构** — 创建分类、组织文档层级

### 5.3 知识库检索

知识库支持两种检索方式：

- **混合检索** — 综合语义相似度和关键词匹配
- **过滤检索** — 按分类、标签等条件筛选

## 6. 智能记账

### 6.1 AI 对话记账

直接在对话中描述记账需求，AI 会自动识别并生成记账凭证。例如：

```
用户：今天收到客户货款50000元，银行转账
AI：已为您生成收款凭证...
```

### 6.2 记账面板

点击首页的 **智能记账** 卡片，打开记账面板：

| 功能 | 说明 |
|------|------|
| 凭证管理 | 创建、编辑、删除、查询凭证 |
| 科目管理 | 管理会计科目 |
| 账套设置 | 配置账套参数 |
| 期末结转 | 自动生成期末结转凭证 |
| 财务报表 | 查看资产负债表、利润表等 |

### 6.3 凭证编辑

1. 点击 **新建凭证** 按钮
2. 填写凭证日期、摘要、借贷科目和金额
3. 系统自动校验借贷平衡
4. 保存凭证

## 7. 记忆系统

### 7.1 什么是记忆系统

记忆系统让 AI 能够记住您的偏好和对话历史，提供更加个性化的服务。

### 7.2 记忆功能

| 功能 | 说明 |
|------|------|
| 偏好提取 | AI 自动从对话中学习您的偏好（如喜欢简洁/详细的回答） |
| 话题连续性 | 多轮对话中保持话题连贯 |
| 重复意图检测 | 避免重复回答相似问题 |
| 记忆分支 | 不同话题使用独立的记忆分支 |

### 7.3 记忆看板

点击侧边栏进入 **记忆看板**，可以查看和管理 AI 对您的记忆：

- 查看各记忆分支
- 管理用户偏好设置
- 查看跨分支关联

## 8. 多媒体功能

### 8.1 图片识别

上传图片后，AI 会自动识别图片内容并回答相关问题。支持：

- 截图识别
- 照片描述
- 图表数据分析
- 文字识别（OCR）

### 8.2 语音输入

点击输入框左侧的 **🎤** 按钮，可以通过语音输入问题。

1. 点击麦克风按钮开始录音
2. 说话完成后再次点击结束录音
3. 系统自动将语音转为文字并发送

### 8.3 语音播放

鼠标悬停在 AI 回复上，点击 **🔊** 按钮，AI 会朗读回复内容。

- 支持长文本自动分段播放
- 播放过程中会显示进度（如 2/5 表示第2段共5段）
- 再次点击可暂停播放

### 8.4 文生视频

点击首页的 **文生视频** 卡片：

1. 输入视频描述文字（建议详细描述画面内容）
2. 选择视频生成模型
3. 点击 **生成** 按钮
4. 等待生成完成（通常需要1-3分钟）
5. 生成完成后可预览和下载视频

## 10. 文档编辑与导出

### 10.1 文档编辑

在对话中点击消息的 **更多（⋯）** 按钮，选择 **转文档**，可以将 AI 回复转换为可编辑的富文本文档。

编辑器支持：

- 标题、加粗、斜体
- 有序列表、无序列表
- 表格插入
- 代码块
- AI 润色（正式书面语 / 精简表述 / 专业术语）

### 10.2 文档导出

编辑完成后，可以导出为以下格式：

| 格式 | 说明 |
|------|------|
| **Word (.docx)** | 完整保留格式，适合打印和分享 |
| **PDF** | 固定排版，适合归档 |
| **Markdown (.md)** | 纯文本格式，适合开发者 |

## 12. 常见问题

### Q: AI 回复不准确怎么办？

A: 可以尝试以下方法：
1. 开启 **联网搜索** 获取最新信息
2. 上传相关文档到 **知识库**，让 AI 基于您的资料回答
3. 在提示词中提供更多上下文信息
4. 尝试切换不同的 AI 模型

### Q: Agent 执行失败怎么办？

A: 常见原因和解决方法：
1. **网页结构变化** — 重新描述任务让 Agent 重新执行
2. **需要登录** — 先手动登录目标网站，再启动 Agent
3. **网络超时** — 检查网络连接后重试

### Q: 语音功能无法使用？

A: 请确认：
1. 浏览器已授权麦克风权限
2. 使用的是 HTTPS 或 localhost 访问
3. 麦克风设备正常工作

### Q: 如何导出对话记录？

A: 鼠标悬停在 AI 回复消息上，点击 **更多（⋯）** 按钮，选择导出格式（Word/PDF/Markdown）。

### Q: 记忆系统会泄露隐私吗？

A: 所有记忆数据存储在您的本地设备或私有服务器上，不会上传到第三方。您可以在记忆看板中查看和删除 AI 对您的所有记忆。
